# 文件回忆

当用户只记得「大概是什么时候」「是什么类型」「好像在某个文件夹」时：

1. 先用 `search_files`，把用户原话里的时间、类型、业务词一起传进去。
2. 看 `interpreted` 里的关键词、类型和时间的理解是否正确；不对就换关键词再搜。
3. 结果太多时，加类型或时间范围；结果太少时，去掉修饰词，只留业务词。
4. 找到候选后，用 `get_file_info` 确认修改时间和路径。
5. 回答时说清「我为什么觉得是这份」，并给相对路径。
6. 如果用户记得的是内容里的某句话，而不是文件名，用 `search_content`。文本文件的命中可以用 `read_file` 带行号复核；PDF/DOCX 只有检索片段，引用时说“第 N 页 / 第 N 段”，不要假装读过全文。

不要编造路径。索引里没有就说没有，并建议用户重建索引或换关键词。
